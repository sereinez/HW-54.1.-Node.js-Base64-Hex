# Homework #7 — Encoding/Decoding Utils

Невеликий JS-проєкт із набором утилітарних функцій для перевірки debug-режиму та кодування/декодування рядків у Base64 та Hex.

## Опис

Проєкт містить реалізацію функцій згідно з технічним завданням:

1. **`isDebugMode()`** — перевіряє, чи додаток працює в режимі розробки (`NODE_ENV === 'development'`).
2. **`encodeToBase64(...args)` / `encodeToHex(...args)`** — об'єднують довільну кількість рядків через `:` та кодують результат у Base64 або Hex.
3. **`decodeFromBase64(str)` / `decodeFromHex(str)`** — декодують рядки назад у звичайний текст.
4. **`safeDecodeFromBase64(str)` / `safeDecodeFromHex(str)`** — безпечне декодування з попередньою валідацією формату вхідного рядка та обробкою помилок.

## Структура проєкту

```
├── index.html   # Точка входу — підключає main.js
├── main.js      # Вся логіка: функції + приклад виконання

```

## Як запустити

Проєкт працює повністю в браузері, без Node.js та без сервера:

1. Відкрий `index.html` подвійним кліком у будь-якому браузері.
2. Відкрий консоль розробника (`F12` → вкладка **Console**).
3. Побачиш результати виконання всіх функцій із прикладу використання.

## Технічні деталі

- Кодування Base64 реалізоване через нативні браузерні `btoa` / `atob`.
- Кодування Hex реалізоване вручну через `TextEncoder` / `TextDecoder`.
- Валідація вхідних рядків у `safeDecode*` функціях виконується регулярними виразами.
- Код написаний на ES6+ (стрілкові функції, rest-параметри, шаблонні перевірки).

## Приклад використання

```javascript
const encoded = encodeToBase64('john@email.com', '123', 'extraData');
console.log(encoded); // -> закодований рядок

const decoded = decodeFromBase64(encoded);
console.log(decoded); // -> 'john@email.com:123:extraData'
```
